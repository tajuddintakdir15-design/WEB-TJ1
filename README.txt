
FTrust Studio - Static Website
------------------------------
Files:
  - index.html
  - styles.css
  - script.js

Cara cepat melihat di lokal:
  1. Buka index.html di browser.

Deploy ke internet (pilihan cepat):
  - GitHub Pages:
    1. Buat repo di GitHub.
    2. Upload semua file.
    3. Settings -> Pages -> pilih branch main -> root -> Save.
  - Netlify:
    1. Daftar Netlify.
    2. Add new site -> Deploy manually -> drag & drop folder.

Untuk form aktif: gunakan Netlify Forms atau Formspree.

Edit konten (logo, alamat, teks) langsung di index.html.
